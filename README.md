# Praxamark feedback

This is where people who use [Praxamark](https://praxamark.com/) report problems and suggest ideas, in public. Each one gets its own page, a status and a thread.

Read and watch. Mark and cite. Own it.™

## How to take part

- **Report a problem:** something didn't do what Help says it does. [Open the form](../../issues/new?template=problem.yml).
- **Suggest an idea:** something you were trying to do that Praxamark doesn't do, or does the long way. [Open the form](../../issues/new?template=idea.yml).
- **Already there?** Search the [open issues](../../issues) first. A comment saying how it affects you, or how you'd use the idea, helps more than a new issue.

In Praxamark, the Feedback page and the bar's **Report** open these forms with your version and browser filled in.

## Everything here is public

Don't post anything private: no personal material, no pages you can't name, no keys. For those, email:

- **feedback@praxamark.com:** private problems and ideas.
- **praxamark@identitypraxis.com:** security reports (see [SECURITY.md](SECURITY.md)), licences and business.

## What this repository holds

Only these forms and notes. Praxamark's code isn't here and isn't published.
